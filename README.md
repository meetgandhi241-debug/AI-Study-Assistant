# AI Study Assistant Pro

An AI-powered study assistant built with Streamlit and Gemini AI.
## Problem Statement

Students often struggle to get quick explanations, practice questions, and organized study material in one place.

## Solution

AI Study Assistant Pro uses Gemini AI to answer questions, generate MCQs, summarize PDF notes, and create personalized study plans.

## Features

| Feature | Available |
|----------|----------|
| Question Answering | ✅ |
| MCQ Generation | ✅ |
| PDF Summarization | ✅ |
| Study Planner | ✅ |
| Progress Tracking | ✅ |
| Chat History | ✅ |
